BBMP Smart Garbage – Local Demo

WHAT THIS IS
A mobile-friendly browser prototype for household registration, daily waste handover photo submissions, GPS capture (with permission), and a local JHI dashboard. It supports English and Kannada UI labels.

HOW TO OPEN
1. Extract this ZIP on a computer or Android phone.
2. Open index.html in a modern browser.
3. For camera/GPS permissions, browsers may require HTTPS or localhost. Opening a local file may allow photo selection but GPS can be blocked.
4. For a quick phone test, host the folder on an HTTPS static host.

IMPORTANT LIMITATIONS
- This is NOT an official BBMP app and is NOT published on Google Play.
- Data and photos are stored only in the current browser/device using localStorage. Residents on different phones cannot share records with an officer dashboard.
- No OTP, cloud database, real-time vehicle tracking, official weighbridge integration, or secure officer login is included.
- Use dummy/test information only. Do not collect real residents’ personal data until an approved privacy notice, consent process, access controls, secure backend and BBMP authorization are in place.
